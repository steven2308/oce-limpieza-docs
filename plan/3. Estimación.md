## Horas comerciales ajustadas por IA

Uso intensivo de IA sobre este stack (starter Limpieza ya con auth, notificaciones, audit, i18n, shell Vue + DRF; formularios Castivas como spec de campos), **45 %** de reducción del esfuerzo humano neto de **implementación**.

**Por qué 45 % (no 70 %+):** el dominio SR/jornada/roles es net-new; la máquina de estados y el UAT multi-rol no se delegan a codegen.  
**Por qué no bajar a 25 %:** reuso real de plataforma + pantos Form. 1–4 + equipo ya en el stack.

| Concepto | MVP | Fase 2 | Fase 3 | Total |
|----------|----:|-------:|-------:|------:|
| Horas brutas (optimistic) | 250 | 98 | 88 | 436 |
| Reducción IA | 45 % | 45 % | 45 % | 45 % |
| **Horas efectivas (comercial)** | **138** | **54** | **48** | **240** |

Fórmula: `efectivas = brutas × (1 − 0,45)`.

| Concepto | Valor |
|----------|------:|
| Escenario comercial | Optimistic |
| Reducción IA | 45 % |
| Horas efectivas MVP (oferta inicial típica) | **138** |
| Horas efectivas programa completo (MVP+2+3) | **240** |
| Tarifa | *acordar* (USD o COP / h) |
| Fee implementación MVP | 138 × tarifa |
| Fee programa completo | 240 × tarifa |

### Lo que la IA no reduce

- UAT y validación de reglas con Castivas  
- Ambigüedades de dominio (bandas de categoría, lista de Services, insumos)  
- Security review  
- Migración de datos históricos (si la piden)  
- Trabajo del lado QuickBooks / Intuit  
- Capacitación y change management  

Referencia interna (no comercial): moderate bruta MVP **344 h**; con el mismo 45 % → ~189 h efectivas si el alcance resbala.

## Orden de entrega y riesgos

1. **MVP** — catálogo Rate + solicitud → asignación → jornada → queja → tabla servicios por rol → horas/montos (matar Trello + Workforce en piloto).  
2. **Fase 2** — sugerencias, mapa GPS, supervisión, feedback.  
3. **Fase 3** — QuickBooks / facturación contable, inventario.  

| Riesgo | Efecto |
|--------|--------|
| RF no validados / alcance creep (app, pasarela) | Sube a moderate o +fase |
| Bandas de categoría / Services carpet sin datos Castivas | Seed vacío; Ops carga Rates — no bloquea código |
| QuickBooks API / permisos Intuit lentos | Fase 3 moderate o solo export CSV |
| Adopción empleados (GPS denegado, móvil viejo) | Ahorro B más lento; flag “GPS no disponible” |
| Sin coordenadas en propiedades | Sugerencia por distancia y flag radio degradan a zona manual |
