# Limpieza — Inputs

Index of **source materials** for Limpieza (not generated project docs).

## Pattern

| Type | Location / naming | Notes |
|------|-------------------|--------|
| Meeting notes | `meetings/YYYY-MM-DD-topic.md` | Summaries only; link recordings externally |
| Spreadsheets / exports | Add under this folder | Large binaries stay out of git (see `.gitignore`) |
| Images / diagrams | [images/](images/) | Screenshots, whiteboard photos |
